## Media Recommender
A cross-media recommendation system that identifies and suggests similar movies, TV shows, and games to enhance content discovery.

## Features
- Find similar media
- Save favorite movies, TV shows, and games.
  
## Built With
- React
- Flask
- FireBase
- ElasticSearch
